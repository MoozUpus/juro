# Advice scenarios

Advice.uz material may inform internal scenario design, user-language patterns,
or evaluation cases. It is not an authoritative legal source and must not appear
as a verified citation in a user answer.

Production Advice ingestion and sitemap discovery are disabled. Existing parser,
queue, index, or historical staging code does not change that runtime fact and
must not be presented as a live production corpus.

If Advice-derived material is used to design a test, the expected legal answer
must be independently grounded in current Lex.uz evidence and reviewed through
the ordinary evaluation workflow. Advice text must not be copied into production
prompts or product analytics as user content.
