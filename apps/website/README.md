# JURO — «Юрист в кармане»

Интерактивный frontend-прототип LegalTech-платформы JURO на Next.js, React и TypeScript.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет терминал.

## Демонстрационные сценарии

- лендинг, регистрация, вход, восстановление пароля и онбординг;
- персональный кабинет с уведомлениями, лимитами и быстрыми действиями;
- AI-юрист с реалистичным ответом и имитацией нового ответа;
- голосовой режим с AI-аватаром и состояниями разговора;
- загрузка договора, прогресс анализа и интерактивная карта рисков;
- пошаговый план действий с прогрессом и календарём;
- конструктор документа с предпросмотром;
- поиск живого оператора и демонстрационная очередь;
- история, защищённое хранилище, тарифы, профиль и настройки;
- адаптивная мобильная навигация и RU / UZ переключатель.

Демонстрационные данные хранятся только в браузере. Backend, платежи, телефония и AI API не подключены.

## Структура

- `app/JuroApp.tsx` — продуктовые экраны, навигация, mock-сценарии и состояние;
- `app/globals.css` — дизайн-система, компоненты, desktop и mobile responsive rules;
- `app/page.tsx` — точка входа.

## Бренд-ассет

В прототипе используется кодовый знак, воспроизводящий утверждённую концепцию J + галстук + карман и фирменную палитру. Перед production-передачей замените его на оригинальный экспорт утверждённого логотипа без изменения его пропорций.
