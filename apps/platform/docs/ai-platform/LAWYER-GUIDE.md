# Lawyer guide

Lawyer handoff starts with an anonymized request for conflict checking. A conflict result alone grants no case access. A customer must confirm a separate, auditable grant; revocation ends access. The current staging slice does not claim a complete marketplace, payment, video/audio provider, or public lawyer-profile workflow.

## Ordinary phone contact (local candidate)

Choosing **No conflict · agree to contact** records the assigned lawyer's
request-scoped phone-sharing consent; it does not expose the customer or case.
Only after the customer separately grants case access and reciprocal phone
disclosure can either participant press **Show number**. The API returns only
the counterpart's current protected phone, records a content-free reveal audit
event and opens the device dialer.

Revoking case access immediately removes phone access for both sides. JURO does
not place or record the ordinary call. Audio/video controls remain honestly
disabled until a provider is selected and tested.
