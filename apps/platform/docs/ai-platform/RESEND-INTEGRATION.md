# Resend integration

Resend is configured only as a server-side staging secret (`RESEND_API_KEY`). OTP, security email and operations-alert workers use the configured `EMAIL_FROM` identity; values are never read from Cloudflare or committed. Provider circuit and legal corpus alerts share the same server-only, idempotency-keyed transport while retaining separate content-free D1 job tables. The recipient remains a server-side variable and is never stored in either alert job. Delivery is not claimed solely from secret presence. Migration `0089`, a controlled legal-corpus alert and a received staging email remain unverified remotely; production sender-domain verification and end-to-end deliverability remain release gates.
